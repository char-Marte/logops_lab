# LogOps Lab v0.1

## Overview

LogOps Lab is a small Linux and Python project created to practice basic log analysis, shell scripting, automation and technical documentation.

The goal of this project is to simulate a simple log monitoring workflow, where a log file is analyzed to count different types of events, such as INFO, WARNING and ERROR.

This project is part of my learning path toward DevOps, Cloud, Linux administration and cybersecurity fundamentals.

## Project Structure

logops_lab/
├── app.log
├── sys_report.sh
├── log_analyzer.py
├── report.txt
└── README.md

## Files

### app.log

A sample log file containing system events.

### sys_report.sh

A Bash script that analyzes the log file using Linux commands.

It displays:

- Current user
- Current directory
- Current date
- Number of ERROR events
- Number of WARNING events

To run:

chmod +x sys_report.sh
./sys_report.sh

Alternative execution:

bash sys_report.sh

### log_analyzer.py

A Python script that reads the same log file and counts the number of INFO, WARNING and ERROR events.

To run:

python3 log_analyzer.py

### report.txt

A text report generated by the Python script.
